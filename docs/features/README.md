# CommerceFlow Lab 功能说明

从业务模块查找入口、操作流程、金额与状态口径。版本验收记录见 [已办](../IMPLEMENTED.md)，待开发功能见 [项目计划](../TODO.md)。

| 功能模块 | 已具备的能力 |
| --- | --- |
| [账号、商品与购物车](ACCOUNT-CATALOG.md) | 邮箱登录、角色授权、店铺入驻和审核、商品与评价、地址、购物车、再次购买 |
| [结算、运费与优惠券](CHECKOUT-COUPONS.md) | 按选中商品计价、地区运费模板、单商家满减券、分摊和快照 |
| [订单、取消与履约](ORDERS-FULFILLMENT.md) | 订单历史、取消恢复、商家履约、正向和退货物流、收货与自动完成 |
| [支付、退款与售后](PAYMENTS-AFTER-SALES.md) | 三渠道模拟支付、原路全退、部分退款、退货验收和库存回补 |
| [库存与商家库存中心](INVENTORY.md) | 可售和预占、支付扣减、取消释放、库存调整、投递对账 |
| [外部系统模拟器](SIMULATORS.md) | 支付与物流模拟服务、管理入口、异步回调与对账 |
| [部署、监控与验收](OPERATIONS.md) | Docker、Flyway、定时任务、Prometheus 告警、隔离验收 |
