# 支付、退款与售后

## 支付如何完成

商城按订单应付快照创建支付宝、微信支付或银联模拟收银台。顾客可以查看支付回执，失败或尝试过期后可在整单付款期限内换渠道。支付编排持有支付与退款记录。模拟平台回调校验签名、时间戳与随机数，回调与 Outbox 事件可重试，重复处理使用幂等键。库存预占凭证通过门禁后才允许付款，成交后提交库存扣减。

## 全额退款与按行部分退款

- 已支付未发货订单可整单原路全退。顾客和商家可查看退款状态及渠道结果。
- 顾客从订单行发起部分退款，可先查看剩余数量和可退金额，再提交数量与原因。商家审核。未发货部分退款同步收窄履约范围，退款达成后回补对应数量。
- 已收货实物可按订单行申请退货，商家同意后由顾客登记退货运单，商家验收登记实收数量，依据通过验收的记录执行退款和库存回补。
- 同一支付单可有多笔退款，各笔独立对账。请求 ID、退款编号和库存回补操作 ID 用于幂等。累计退款受原支付金额约束。

## 实付、运费与库存

商品退款以购买时订单行净额为基础。订单用了优惠券时，先扣除该行的优惠分摊再计算可退金额。先前已处理的数量和金额会占用剩余额度。未发货场景首笔部分退款保留运费，全部商品退款完成时由最后一笔结算符合条件的原运费。已发货退货默认保留原运费。库存只根据真实补偿或实际验收数量回补，每次操作有唯一流水。
