# 部署、监控与验收

## 环境与数据

Docker Compose 启动 Angular 门户、各业务服务、独立 MySQL 和消息中间件。Flyway 管理各库独立迁移。升级按依赖先迁移，再启动 API 服务，最后切换门户。日常数据卷与隔离验收环境分开，新版本验收包含历史订单金额、退款回执和归档命令比对。

商城持有身份、地址、购物车、运费模板、优惠券活动、顾客券、结算恢复和部分业务投递。订单、支付编排、履约、目录、库存和通知各自持有自己业务的数据。跨服务写入通过业务 ID、持久任务、Outbox/Inbox 或签名契约协调。

## 调度与监控

通用定时任务支持 Database、RabbitMQ 和 RocketMQ 主触发。数据库对账覆盖消息代理不可用、重试、租约失效和进程重启恢复。任务创建时记录策略快照，管理员可按任务类型查看和调整生效策略。

Prometheus 抓取服务健康、命令积压、待对账、异步事件发布失败、消费滞后和死信。Alertmanager 负责告警路由，Grafana 提供观测入口。告警按服务和数据所有权配置，触发与恢复条件见 [告警说明](../ALERTING.md)。

PowerShell 7 验收脚本覆盖基础商城、Flyway、结算、退款、领券、并发、取消与中断恢复。脚本入口、参数和隔离门禁见 [脚本审计](../SCRIPT-AUDIT.md) 和 [验收体系](../VERIFICATION-SYSTEM.md)。
