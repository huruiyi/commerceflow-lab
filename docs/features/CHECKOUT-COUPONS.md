# 结算、运费与优惠券

## 统一计价与运费

顾客在购物车勾选商品、选择收货地址后，商城按当前商品单价、数量、商家和目的地生成服务端报价。商家可配置默认运费与地区覆盖规则。报价返回商品小计、运费、优惠和实付总额。确认时要求提交报价 ID，商品或地址等计价条件变化时按当前数据复核并要求重新试算。

商城 V74 按标准全称保存中国省级运费。「安徽」和「安徽省」共用一行，停用后两种地址都按店铺默认运费报价。直辖市、自治区和特别行政区的常用简称同样适用。其他国家继续按国家和省州组合匹配。

升级前检查各店是否同时保存同省的两种写法，包含已停用规则。若有冲突，由商家在 V73 模板中确认保留的费率和启用状态，合并后再迁移。V74 遇到重复主键会回滚该条更新，保留原始规则。

订单服务保存单价、数量、商品原额、行优惠、运费、币种、应付总额和收货地址快照。支付、详情和售后读取订单快照。V54 为历史订单回填购入时金额，V8 新增可选券 ID，历史订单无需绑定优惠券。

## 首版单商家满减券

商家在「满减活动」填写名称、商品金额门槛、减免额、名额和结束时间，再选择「发布领券活动」。发布后，顾客可在优惠券页自行领取。门户从当前时刻开始活动，API 也支持指定开始时间。门槛须大于减免额。活动可停止，金额、名额及使用期发布后固定，变更条件用新活动。停止后关闭新增领券与新下单用券，已锁定的订单仍按其快照处理。

顾客从「优惠券」查看活动、领券并查看券包。每位顾客每个活动领一次，重复请求返回同一张券。库存名额按已发券数计算，退回顾客的券仍属于该顾客。购物车自动读取券包，顾客可选择一张券，也可通过「去领券」查看活动。仅单商家订单可用券，券必须属于当前顾客、匹配商家且处于活动有效时间内。报价时以参与结算的**商品原额**校验使用门槛，运费单独计价。

## 按订单行分摊

以分为单位，用每行原额占商品合计的比例计算满减。先取每行的整数分，再按余数从大到小补足差额。同余数按商品 ID、输入位置排序。三条各 1.00 元商品减 0.01 元时，稳定排序的第一条承担 0.01 元。这样每一分优惠都有归属，行优惠之和等于券减额，订单应付等于商品原额加运费再扣优惠。

订单服务持久化券 ID、整单优惠和订单行优惠。详情可查看商品小计、运费、总优惠和行优惠。部分退款以原单行实付为起点，按实际退款数量和累计台账计算。剩余商品按下单价继续履约。整单未发货售后退尽时按原运费规则结清，已核销的券仍保持已使用。

## 锁券、核销与中断恢复

| 状态 | 含义和转换 |
| --- | --- |
| `AVAILABLE` | 已领取且未占用。活动处于有效期且未停止时可报价。 |
| `HELD` | 确认下单事务锁定券并写入持久结算记录。并发确认只有一个订单能持有该券。 |
| `USED` | 订单服务确认支付成功后核销。渠道回调重试和售后退款继续引用原订单。 |
| `EXPIRED` | 可用券已过有效期，或未支付订单释放时活动已到期。 |

商城 V56 保存活动、顾客券与持久结算记录。确认下单后，商城以同一订单号向订单服务完成建单。若商城在远程写入前后退出，恢复任务用已冻结的计价和地址补完订单绑定、预占投递、超时任务和回执。重复提交返回同一订单。订单结论未确定时保留锁券状态。主动取消、超时关闭或预占拒绝按原结算记录释放，券仍在有效期内时恢复未占用状态。已停止活动的券不能再次结算。存量锁券的结果以订单服务状态为准。

配置和用户接口见 [API 索引](../API.md)。支付核销和退款见 [支付、退款与售后](PAYMENTS-AFTER-SALES.md)。
