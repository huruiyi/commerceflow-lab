# 账号、商品与购物车

## 登录与授权

商城门户使用邮箱和密码登录。后端以 BCrypt 保存密码，通过 Redis 管理服务端 Session。勾选记住登录可保留 14 天，注销会撤销对应令牌。写请求由 Angular 结合 CSRF Cookie 和请求头提交。登录失败触发限流。菜单按顾客、商家和管理员角色显示，服务端还会检查订单、购物车、地址和商家资源归属。管理员可查询用户。门户可切换中英文，错误使用稳定错误码。

## 浏览商品与评价

目录服务持有商品资料、翻译、价格、上下架状态与版本。顾客可浏览、搜索和排序商品，详情展示评分和评价。收货后，顾客从订单行进入评价，每行限评一次，评价计入对应商品聚合评分。商家修改自己的商品。库存服务维护各 SKU 的库存并消费目录事件以同步库存所需的商品快照。

目录列表只读取当前页的平均评分和评价总数。打开商品详情时显示最新 5 条，顾客可以继续翻页。评价页读取失败时保留已显示的评价，并可重试原页。

商品详情返回 404 时，门户提示商品不存在或已下架。在售商品可售量为 0 时显示售罄，数量超出可售量时提示减少件数。库存超时或不可查时，保留已加载的商品信息并提供重试，确认可售量前暂停加购。重试重新核对详情和可售量，结算仍由服务端校验。浏览器验收见[商品详情错误状态](../IMPLEMENTED.md#2026-11-23-商品详情错误状态验收)。

### 商品全文搜索与筛选

顾客通过导航搜索进入商品列表，可同时指定店铺、最低价和最高价。价格筛选包含两端边界。
搜索使用当前语言的商品名称、简介与描述，缺少译文时使用商品原文。空白分隔的搜索词须全部匹配，
例如「无线 键盘」可找到「无线机械键盘」，会排除只含「无线」的耳机。列表默认按全文相关性排序，
也可切换价格或评分排序。分页同分时按商品编号排序。

目录服务通过目录事件更新搜索投影。启用 Elasticsearch 的环境优先查询 Elasticsearch。
日常基线和回退使用 MySQL 搜索投影。商城按店铺当前状态限制公开结果，商品详情读取目录权威值，
结算按当时的售价、可售状态和库存重新核对。清空或损坏的派生索引可由管理员发起全量重建。
运行方式见 [Elasticsearch 商品搜索](../architecture/CATALOG-SERVICE-EVOLUTION-PLAN.md#7-elasticsearch-商品搜索)。

目录页每页 12 件。翻页时保留关键词、店铺、价格和排序，应用新筛选或切换排序后返回第一页。
桌面可跳到指定页，窄屏显示当前页和总页数。页面链接可直接打开到所选条件及页码。

## 商家入驻与店铺归属

管理员在「店铺审核」创建商家账号。商家登录后从「我的店铺」提交名称和介绍，审核通过后店铺对外可见。驳回后可修改资料并重新提交。管理员可以停用或重新启用店铺，商家可维护自己的公开名称和介绍。

首版一个商家账号对应一家店。商城 V58 为存量商家回填启用的店铺，原商家 ID 就是店铺的稳定标识。目录商品、库存快照及订单行沿用原商家归属，修改店名不会改变历史订单归属。顾客可从商品详情进入店铺，按每页 12 件浏览该店当前公开的商品。

商家从商品管理创建草稿，目录用请求 ID 去重，同一事务发布创建事件。库存收到事件建立零余额快照，商家可按既有库存管理规则调整数量，商品上架后对顾客可见。停用店铺后公开页、商品和新交易入口关闭，原订单的确认、发货、售后和退款仍按成交归属处理。购物车可保存来自多个店铺的商品，每次结算仅选择同一家店的商品。

## 收货地址、购物车与再次购买

- 顾客可新增、编辑、删除地址并设置唯一默认地址。结算时可选择本人的其他地址，订单保存当时的收货快照。
- 相同商品加入购物车时合并数量。顾客可改数量、移除、清空和勾选部分商品。确认下单只清理参与该次结算且数量仍等于原快照的购物车行。
- 购物车按车内商品批量刷新当前语言的商品名和价格，并另查可售库存。已下架、店铺未开放或不存在的商品保留原购物车快照，可移除，不能结算。
- 已完成订单支持再次购买。系统根据当前商品售价和销售状态重建购物车行，相同商品与已有行合并。同一个请求 ID 重试会返回原回执，数量只增加一次。

下一步操作见 [结算、运费与优惠券](CHECKOUT-COUPONS.md)。接口见 [API 索引](../API.md)。
