# 库存与商家库存中心

库存服务持有可售、预占、已售、调整流水、出库记录与出库事件。下单预占增加预占量，支付提交将预占转成已售，未支付取消释放预占，售后按已确认退款和退货验收回补。商家可查询自己的库存、发起增减调整并查看原因和流水。

商城持有库存命令投递和命令结果账本。投递端持久化命令与业务关联，库存服务用 Inbox 和业务键去重。支付前检查真实预占，库存提交要求完整预占凭证。拒绝、暂时失败与需要人工对账均可独立跟踪。

商城告警监控未完成投递、最老命令等待时间和待人工对账。库存服务单独负责出库事件积压与发布失败告警。已确认、已关闭记录退出活动积压监控。五笔历史缺证测试订单仍归档，原预占命令关闭，库存流水保持为零。精确指标状态和运维检查见 [告警说明](../ALERTING.md)。
